# Operations

The web service exposes `/up` for healthchecks. Run `/app/app migrate` before releasing new versions. Use a separate queue worker with the same application and database settings.

```bash
npm run check
npm run build
go vet ./...
go test -race ./...
```

The root README covers local setup. Do not run migrations alongside an incompatible worker version. Monitor delivery, bounce, and complaint events in Resend until webhook ingestion is available.
