# Campaigns

Campaigns start as editable drafts. The editor supports GFM Markdown, MDX, and React Email templates. Preview the message on desktop or mobile before reviewing and sending it.

Each recipient gets a separate queue job. Fan-out is transactional, and recipients never see each other's addresses. Email content and wrappers are generated from `resources/js/emails` and `resources/emails`.

Current metrics reflect local queue states and provider acceptance. `accepted` does not mean delivery to an inbox. Open, click, bounce, and complaint events are not implemented yet.
