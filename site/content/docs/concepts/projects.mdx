# Projects

Each project has a name, slug, public domain, description, and sender address. The dashboard manages multiple projects. Subscribers, campaigns, metrics, and exports are scoped to the selected project.

After creating a project, configure its public domain and verify its sender domain with Resend. The public page is available at `/subscribe` on the project's hostname or at `/subscribe/{slug}`. The sender domain can differ from the public page domain.

The dashboard uses the canonical hostname from `APP_URL` for authentication. Sessions are not shared across hostnames.
