# Vukem Email

Vukem Email is an open source newsletter manager for multiple projects. The backend uses [Vukem](https://vukem.dev/docs/introduction) and Go; the dashboard uses Inertia v3, React, and shadcn/ui.

Administrative access requires Google OIDC with the verified address `aleexgvieira@gmail.com`. Each project has its own domain, sender, subscribers, and campaigns.

## Features

- Public sign-up with double opt-in and signed unsubscribe links.
- Campaign editor for GFM Markdown, MDX, and React Email, with previews.
- Persistent per-recipient queue with retries and provider idempotency.
- Project metrics, filters, and CSV export.
